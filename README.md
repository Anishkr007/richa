# Two Stars — Vellore to Dehradun ✦

A one-page story and confession website built for Richa by Anish.

## About
- **Her**: Richa (Dehradun)
- **Me**: Anish (Vellore)
- **Theme**: "Two Stars" connected across ~2,000 km.
- **Palette**: Deep indigo (`#14122b`), dusk purple (`#2b2150`), warm star gold (`#ffd9a0`), soft rose (`#f2a7b8`).

## Features
- **Opening Screen**: SVG celestial arc connecting Vellore and Dehradun with gentle star pulse animations.
- **Background Music**: Starts looping at 60% volume upon pressing play (`song.mp3`).
- **Arched Photo Gallery**: Responsive, softly tilted arched frames with handwritten captions and missing-image fallbacks.
- **Heartfelt Message & Confession**: Handcrafted lines leading into a prominent handwritten *"I like you."*
- **Interactive Question**: "Want to get coffee with me when we meet?" with custom floating hearts response on "Yes".
- **Audio Controls**: Fixed top-right mute/unmute toggle.
- **Mobile-First & Accessible**: Tested for mobile screens, $\ge$48px touch targets, `:focus-visible` styling, and `prefers-reduced-motion` support.

## Running Locally
Double-click `index.html` to open in any browser, or run:
```bash
node server.js
```
Then visit `http://localhost:3000/`.
